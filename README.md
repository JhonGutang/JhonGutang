I design and deliver full applications end to end — APIs, data models, and the interfaces built on top of them. I work primarily in .NET and PHP on the backend, and adapt readily across React, Vue, and Angular on the frontend depending on what a project already uses. My focus is on clean data schemas, dependable deployments, and code that's easy for the next engineer to pick up. I'm also leaning into AI-driven development, using it to move faster while keeping the same standard for clean, maintainable code.
